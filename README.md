# VOID X ARENA 🎮

**Competitive Esports Tournament Platform for Free Fire Champions**

VOID X ARENA is a high-performance, modern gaming tournament web platform engineered for competitive Free Fire mobile players.

---

## ⚡ Core Features

- **The Arena Is Live**: Real-time tournament listings (Battle Royale Squad, Solo High-Roller, Clash Squad 4v4 Knockout, 1v1 Precision Duels).
- **Automated Room Pass**: Automated room ID and password distribution directly to players prior to match start.
- **Asymmetrical Game Modes**: Detailed tactical breakdowns of tournament formats.
- **App Download Center**: Download direct Android APK and sync Free Fire Game UID.
- **Fair Play & Anti-Cheat**: Strict mobile-only integrity and referee verification.
- **Hall of Champions & Live Stats**: Viewport-triggered animated metrics and prize distributions.
- **Custom Gaming Experience**: Custom cursor, reactive micro-interactions, responsive 320px–4K support.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom Void X Arena design system
- **Motion & Interactions**: Framer Motion
- **Icons**: Lucide React

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
